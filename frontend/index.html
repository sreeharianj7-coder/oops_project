System Overview

About The System

Engineered for college hostels to replace cumbersome paper registers with an automated, tamper-proof digital attendance workflow.

Purpose & Vision

Hostel management requires strict verification that students are physically present inside their allocated residential perimeter during evening roll-call hours.

The Smart Hostel Attendance Management System enforces accurate verification by combining secure student accounts with real-time GPS coordinate validation computed authoritatively on the Java Spring Boot backend using the mathematical Haversine formula.

Verification Process

How It Works

Step-by-step attendance verification workflow designed to ensure location authenticity.

1

Student Registers

Student signs up with Student ID, room allocation, and encrypted password.

2

Student Logs In

Student authenticates securely to access the personalized dashboard.

3

Opens Attendance

Student accesses the Geolocation Attendance marking module.

4

Location Is Verified

Browser requests GPS access and acquires exact latitude and longitude.

5

Distance Calculated

Java backend computes distance to hostel using Haversine formula.

6

Attendance Recorded

If within permitted 1000m (1 km) radius, attendance is marked PRESENT in MySQL.

7

History Updated

Attendance logs and percentage statistics update instantly.
